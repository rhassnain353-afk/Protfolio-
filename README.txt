RANA HASSNAIN – PORTFOLIO
=========================

FILES
- Open index.html to view the portfolio.
- education.html, skills.html, projects.html and contact.html are the other pages.
- dashboard.html is the content editor.

SECRET DASHBOARD
- From any portfolio page, type 786786 on your keyboard.
- The dashboard opens. Enter 786786 in the secret-key box on first use.
- Change the secret key from the dashboard after unlocking.
- This is a browser-side convenience lock only, not server-grade security.

YOUR IMAGES
- Put profile.png beside index.html for the default profile picture.
- You can also upload a profile picture from Dashboard > Profile & homepage.
- Put result.png beside index.html for your Matric result image.
- Keep the filenames exactly as written.

CV
- Click Download Complete CV (PDF) on the homepage.
- A complete PDF is generated from your current profile, education, skills, interests, projects and social links.

EDITING
- Dashboard edits are saved in the current browser's localStorage.
- This static project does not sync edits between different devices or browsers.
- To publish edits to all visitors, a backend/database or exporting the saved content is required.
- Contact page displays centered email, location and social icons. There is no send-message form.

THEME
- Use the sun/moon button in the navigation for Light/Dark mode.
